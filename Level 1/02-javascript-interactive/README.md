# ARYONIX Interactive Services

A JavaScript-based interactive services website created as part of the Codveda Technologies Web Development Internship.

## About

This project demonstrates how JavaScript can be used to add interactivity and user-focused functionality to a modern website.

The website is designed around ARYONIX, a digital web development and design concept.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Features

- Responsive navigation
- Interactive service cards
- Service information modal
- Project type selector
- Dynamic project recommendations
- Interactive project inquiry form
- JavaScript form validation
- Email format validation
- Success confirmation modal
- Modal close functionality
- Escape-key modal closing
- Smooth scrolling
- Responsive design
- CSS animations and hover effects

## JavaScript Concepts Demonstrated

- DOM manipulation
- Event listeners
- Functions
- Objects
- Conditional statements
- Form handling
- Input validation
- Regular expressions
- Dynamic content updates
- Modal interactions
