# ARYONIX Responsive Business Website

A modern responsive business website created for the Codveda Web Development Internship 2026.

## About

This project demonstrates responsive web design using HTML5 and CSS3. The website was designed for ARYONIX, a digital development and design company.

The layout adapts across desktop, tablet and mobile devices using CSS Flexbox, CSS Grid and responsive media queries.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Media Queries
- Google Fonts

## Features

- ARYONIX logo navigation
- Responsive navigation
- Modern hero section
- Current Focus information card
- Responsive services grid
- Selected work section
- Project cards
- Four-step development process
- Contact call-to-action
- Responsive footer
- Hover animations
- Smooth scrolling
- Mobile-friendly layout

## Responsive Design

### Desktop

- Two-column hero layout
- Four-column services grid
- Three-column project grid
- Four-column process grid
- Horizontal navigation

### Tablet

- Single-column hero
- Two-column services grid
- Two-column project grid
- Two-column process grid
- Adjusted spacing and typography

### Mobile

- Single-column layouts
- Stacked hero content
- Single-column service cards
- Single-column project cards
- Single-column process section
- Simplified navigation
- Responsive buttons
- Vertical footer

## Flexbox Usage

Flexbox is used for:

- Navigation alignment
- Navigation links
- Hero buttons
- Service card content
- Footer alignment
- Responsive footer layout

## CSS Grid Usage

CSS Grid is used for:

- Hero layout
- Services section
- Projects section
- Process section
- Responsive column changes
